# First Steps

Source for the **First Steps** module of the [Workshop 2026](https://spatialturn.github.io/workshop2026.html) materials, part of [Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/).
Published at <https://spatialturn.github.io/intromoduletest/>.

Setup steps and orientation for the workshop: the data platforms used during the workshop (USGS EarthExplorer, Copernicus Data Space, the Census API and GitHub), a short guide to QGIS, and a Python notebook refresher.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/).
It is kept as it was taught at the workshop (Day 1 opening module, for all participants).
